# Agency.Ai
Agency.Ai is a landing website for a digital/AI agency. It presents the agency's brand, services, work and contact details in one clean, easy-to-navigate page. Think of it as the "first impression" a company gives its clients online. So the focus was on a sleek look, smooth layout, and a great experience on both mobile and desktop.

- Clean, modern UI with a polished, professional design
- Fully responsive on every screen size
- Reusable React components, so the code stays neat and easy to maintain
- Smooth, simple user experience

🛠 Tech Stack

React.js
Tailwind CSS
Agency.Ai (project name and branding)

📚 What I learned

- Structuring a project into reusable components
- Building responsive layouts quickly with Tailwind's utility classes
- Writing clean code, and paying attention to small UI details that make a big difference

This was a great hands-on project to sharpen my frontend skills, and I'm looking forward to building more. I'd love to hear your feedback and suggestions!
